
# 🤖 Assistente Inteligente de TI

Projeto de portfólio desenvolvido em Python com o objetivo de auxiliar na análise de mensagens suspeitas e na organização de chamados de suporte técnico.

## 🎯 Objetivo

Desenvolver uma ferramenta que ajude a identificar possíveis tentativas de phishing e facilite a organização de solicitações de suporte de TI.

## 🛠️ Tecnologias

- Python
- Git e GitHub
- Inteligência Artificial (etapa futura)

## 📌 Funcionalidades planejadas

- [ ] Analisar mensagens suspeitas.
- [ ] Identificar possíveis sinais de phishing.
- [ ] Classificar o nível de risco das mensagens.
- [ ] Organizar chamados de suporte.
- [ ] Explorar integração com Inteligência Artificial.
