# Assistente Inteligente de TI

Projeto desenvolvido em Python com o objetivo de analisar mensagens e identificar possíveis sinais de phishing.

## Sobre o projeto

O Assistente Inteligente de TI é um projeto pessoal desenvolvido para praticar lógica de programação, automação e conceitos iniciais de segurança cibernética.

A aplicação analisa mensagens digitadas pelo usuário, identifica palavras e expressões suspeitas e apresenta uma classificação de risco.

## Funcionalidades

- Análise de mensagens.
- Identificação de termos suspeitos.
- Exibição dos motivos do alerta.
- Classificação de risco: baixo, médio ou alto.
- Registro das análises em arquivo de histórico.
- Consulta ao histórico pelo menu interativo.

## Tecnologias utilizadas

- Python
- Visual Studio Code
- Git e GitHub

## Como executar

1. Instale o Python.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto no terminal.
4. Execute:

```bash
py main.py
```

## Limitações

A identificação de possíveis mensagens de phishing é baseada em palavras-chave predefinidas. Portanto, o resultado é uma análise inicial e não substitui ferramentas profissionais de segurança.

## Objetivo de aprendizagem

Desenvolver conhecimentos em Python, lógica de programação, manipulação de arquivos e fundamentos de segurança cibernética.
